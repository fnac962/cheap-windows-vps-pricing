## 下单前必须确认的六件事

- **内存**：2GB 起。1核1G 的档位不要考虑装 Windows，省下的钱会在远程桌面的卡顿里还回去。
- **流量类型**：限制流量型用完会限速（不同系列限到 1M 或 5M），但每月用不完的流量会自动叠加、次月不清零，额外流量可单独购买，常见档位是 200G/50 元、1TB/200 元这一类；且上下行双向计费，别只算一边。
- **硬盘**：默认 30G 起，Windows 装完系统、打完补丁，留给你的空间不多。扩容 SSD 约 0.4 元/GB/月，高效或机械盘约 0.1 元/GB/月，加盘成本比换档位划算。
- **IP 费用**：多数套餐自带 1 个 IPv4，部分区域 IP 单独计价，普通 IP 约 5 元/月；海外节点还能选原生 IP（约 10 元/月）和住宅 IP（约 25 元/月）。
- **退款与试用**：支持 7 天无理由退订（每个账号限 3 次），云服务器和游戏云可 1 元试用 1 天（每款限 1 次，配置越贵试用价越高）。先用这两个机制试错，比看十篇评测管用。
- **备案与实名**：国内节点对外提供网页服务要走备案和过白，香港、日本、美国节点免备案；购买账号需要实名，支付走支付宝或微信。

## 买完之后，把 Windows 跑起来

1. 注册后进控制台，选"云服务器"或"游戏云"，确定区域、线路、流量类型和档位。
2. 镜像选 Windows 2019 或 Windows 2022 数据中心版（官方把 2019 标为推荐），硬盘空间不够就在这一步加购。
3. 创建完成后在控制台查看公网 IP 和初始密码，需要的话直接重置密码。
4. 用系统自带远程桌面（mstsc）登录；连不上就切到控制台自带的 VNC 进去排查。独立 IP 机型直接用 IP 连，NAT 机型走端口映射，记得端口映射方式下把远程桌面入口暴露在共享 IP 上，安全性不如独立 IP 机型省心。
5. 第一次进去先改默认密码、调整端口、补上防火墙规则，再做其他事。宝塔、1Panel、Docker 这类一键预装环境主要针对 Linux 镜像，Windows 下按自己的需求正常装软件即可。
